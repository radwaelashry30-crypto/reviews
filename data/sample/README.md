# data/sample/

First 200 rows of each raw Olist CSV, generated by `backend/scripts/make_data_sample.py` for offline demos and quick EDA checks only. Not used by the training/evaluation pipeline, the shipped model checkpoints, or the backend API -- those all use `data/raw/` and `data/processed/` (already present in this delivery). Row counts and joins are not guaranteed to be referentially complete across files; regenerate with:

```
python backend/scripts/make_data_sample.py --rows 200
```
